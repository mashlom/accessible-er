# Feature: עולמות נוספים לקונספט quest

## הקשר

חמשת העולמות הנוכחיים (אביר, דינוזאורים, פיה, חלל, "אני") נבחרו כנקודת פתיחה.
אך קהל היעד בלניאדו נתניה מגוון תרבותית — ילדים חרדים, ערבים, בדואים, עולים —
וחשוב שלפחות אחד מהעולמות ירגיש "שלהם".

## עולמות מומלצים להוספה

### 🦁 ספארי / חיות אפריקה
- **למה:** ניטרלי תרבותית, פופולרי אצל ילדים מכל הרקעים בישראל.
- **מטאפורות:** בית החולים = מחנה חוקרים בג׳ונגל. רנטגן = מצלמת ציד. בדיקת דם = דגימת שטח. שחרור = חזרה הביתה עם תעודת חוקר.
- **אווטאר:** אריה / ג׳ירפה / פיל — הילד בוחר.

### 🐠 עולם תת-ימי
- **למה:** אוניברסלי, נעים חושית (כחול, שקט, רך), מושך גם ילדות וגם ילדים.
- **מטאפורות:** בית החולים = תחנת מחקר תת-ימית. רנטגן = סונאר. בדיקת דם = דגימת מים. תפר = תיקון הצוללת.
- **אווטאר:** דג / צב / תמנון.

## הערה

אין צורך להוסיף את כולם בבת אחת. מומלץ לבחור אחד בשלב ב׳ לפי פידבק מהצוות
ומשפחות שנסו את הדמו.
