# מה שלומי? · מסע נגיש במלר״ד ילדים
  
אפליקציית דמו להנגשת הביקור במיון ילדים (מלר״ד) עבור ילדים אוטיסטים ומשפחותיהם.
הכלי מלווה את ההורה והילד/ה לאורך המסע, מפחית אי־ודאות, ומכין לפרוצדורות —
בקצב שלהם ובשפה פשוטה.

התוכן הוא פרי עבודתם של **אלו״ט** ושל **צוות המלר״ד** בבית החולים לניאדו.

> הכלי אינו מחליף את הצוות הרפואי ואינו מספק ייעוץ רפואי. זהו דמו לצורכי אפיון —
> מטרתו להראות קונספט ולאפשר לצוות הרפואי להחליט איך תיראה האפליקציה האמיתית.

## קונספטים

הדף הראשי (`#/`) הוא **תפריט של קונספטים**: כיווני UI/UX שונים על אותו תוכן בדיוק,
כדי שאפשר יהיה להשוות ולבחור.

| קונספט | כתובת | מה מאפיין אותו |
| --- | --- | --- |
| **רגוע ומסודר** | `#/calm` | כרטיסים נקיים, צבעים רכים, עומס חושי נמוך |
| **המסע של רוני** | `#/story` | עולם מצויר וספר סיפורים; רוני נוכח בכל מסך, מגיב למגע, והדמות של הילד/ה נוסעת איתו |
| **לדבר עם רוני** | `#/talk` | בלי תפריטים בכלל — שיחה אחת רציפה; רוני תופס שליש מהמסך, זז ומשנה הבעה כל הזמן; ממשק ערב כהה |

הוספת קונספט נוסף מתוארת ב־[CLAUDE.md](CLAUDE.md).

## מה יש בפנים (בכל הקונספטים)

- **חשוב לדעת על הילד/ה שלי (כרטיס התאמות)** — ההורה מסמן במהירות (צ'יפים, בלי
  חובת שם) תקשורת, רגישויות, מה מרגיע, מה מסלים, קושי בבדיקות וביטוי כאב — ומקבל
  כרטיס קצר וגדול להצגה לצוות מהמסך או בהדפסה. סימון רגישות פותח הצעות להתאמות
  שכדאי לבקש. נשמר במכשיר בלבד עם תפוגה של 24 שעות; שום דבר לא נשלח.
- **למה הגענו?** — בחירת סיבת ההגעה (חום, כאבי בטן, חבלה, חתך, אחר). הבחירה
  נשמרת ל־24 שעות (`localStorage` עם תפוגה), כך שרענון דף שומר עליה, ואפשר לעדכן
  בכל רגע. לפי הבחירה מוצג המסלול הצפוי.
- **מה קורה עכשיו?** — שלבי הביקור כ"סטפר" (כולל ייעוץ מומחה), עם משמעות לכל שלב,
  הערכות זמן בטווחים, מה אפשר לבקש, וקישורי הכנה לפרוצדורות של אותו שלב.
  אפשר לסמן "אנחנו כאן" (נשמר ליום).
- **מה עומד לקרות?** — ספריית הכנה חזותית ל־16 פרוצדורות (כולל בדיקת רופא/ה
  והמתנה לתוצאות), עם "סיפור" מודרך שלב־אחר־שלב עם דמות מלווה (רוני).
- **איפה אנחנו?** — מפת התמצאות עם שכבת "עומס חושי" (שקט / בינוני / עמוס)
  ו"לאן ממשיכים מכאן" לכל אזור.
- **מה עושים כשקשה?** — הנחיות קצרות להורה + משפטים מוכנים לצוות שאפשר להציג
  בגדול על המסך ברגע שקשה לדבר.
- **מה אפשר לבקש?** — התאמות לגיטימיות שאפשר לבקש מהצוות.
- **לקראת שחרור** — השחרור כמעבר בפני עצמו: מה קורה בסיום, מה בבית, ומעקב ברפואת
  קהילה.
- **כניסה מהירה ב־QR** — דף ייעודי לצוות בלבד ב־`#/<קונספט>/settings` (לא מקושר
  מהממשק להורים): QR להדפסה כשילוט; ללא הורדה וללא הרשמה.
- **משוב הורים** — שאלון קצר ואנונימי.

שליחת מידע לצוות (אינטגרציה הורה↔צוות) לא מומשה בשלב זה, לפי האפיון —
הכרטיס מוצג פיזית על ידי ההורה בלבד.

## סטאק

- React 18 + TypeScript + Vite
- `react-router-dom` עם **HashRouter** (תואם GitHub Pages ללא הגדרות שרת)
- Client-side בלבד, ללא backend. אין איסוף מידע מזהה.
- כל נתוני המשתמש (סיבת הגעה, שלב במסע, כרטיס התאמות, משוב) נשמרים
  ב־`localStorage` עם תפוגה של 24 שעות — כך שרענון/חזרה באותו ביקור שומרים הכל,
  וביקור חדש מתחיל נקי.
- RTL מלא, גופן Assistant, טיפוגרפיה רספונסיבית (root font-size ב־clamp).

## הרצה מקומית

```bash
npm install
npm run dev        # שרת פיתוח — נפתח ב-http://localhost:5173/
npm run build      # בדיקת טיפוסים + build לפרודקשן אל dist/
npm run preview    # תצוגה מקדימה של ה-build (תחת /accessible-er/)
```

## פריסה ל־GitHub Pages

האתר מוגש מדומיין מותאם — `https://accessible-er.mashlom.me` — ולכן ה־`base`
הוא `/` גם בפיתוח וגם ב־build ([vite.config.ts](vite.config.ts)). קובץ
[public/CNAME](public/CNAME) מועתק אוטומטית אל `dist/` כדי שהדומיין יישמר בכל פריסה.
קיים workflow ב-[.github/workflows/deploy.yml](.github/workflows/deploy.yml) שבונה
ומפרסם אוטומטית בכל דחיפה ל-`main` (יש להפעיל Pages → Source: GitHub Actions).

הערה: `tsc -b` מקמפל את `vite.config.ts`; הפלט מנותב אל `node_modules/.cache`
(ראו [tsconfig.node.json](tsconfig.node.json)) כדי ש־`vite.config.js` מקומפל לא
יסתיר את קובץ ההגדרות האמיתי — Vite מעדיף `.js` על `.ts`.

## מבנה

```
src/
  data/          # תוכן משותף: מסלולים, שלבים, פרוצדורות, מפה, תמיכה, כרטיס
  components/    # רוני והאייקונים המונפשים — משותפים לכל הקונספטים
  hooks/         # usePersistentState, useVisitReason, useSessionAvatar
  lib/           # עזרי localStorage עם תפוגה
  menu/          # תפריט הקונספטים (הדף הראשי)
  concepts/
    registry.ts  # קטלוג הקונספטים
    nav.tsx      # Link/Navigate מודעי־base
    calm/        # קונספט 1 — "רגוע ומסודר"   (/calm)
    story/       # קונספט 2 — "המסע של רוני"  (/story)
    talk/        # קונספט 3 — "לדבר עם רוני"  (/talk)
  App.tsx        # תפריט + מיפוי קונספטים ל־base
```

**כלל הזהב:** התוכן חי ב־`src/data` ומשותף לכל הקונספטים; קונספט הוא עור בלבד.
גם מפתחות ה־`localStorage` משותפים, כך שמעבר בין קונספטים באמצע ביקור לא מאבד
כלום. פרטים ב־[CLAUDE.md](CLAUDE.md).

## מדיה ורישיונות

כל המדיה בפרויקט פתוחה לשימוש חופשי, כולל מסחרי:

- **אנימציות האייקונים** בקונספט "המסע של רוני" (`public/anim/*.json`) הן
  [Noto Animated Emoji](https://googlefonts.github.io/noto-emoji-animation/)
  של Google, ברישיון
  [CC BY 4.0](https://creativecommons.org/licenses/by/4.0/) —
  © Google Inc. ראו [public/anim/NOTICE.txt](public/anim/NOTICE.txt).
  לרענון או להוספה: `npm run anim`.
- **דמות רוני** נכתבה במיוחד לפרויקט (SVG בקוד).
- שאר ה"איורים" הם אימוג'י של מערכת ההפעלה ו־SVG/CSS.

האנימציות נטענות רק כשצריך, ויורדות מהמסך לגמרי כשמכשיר מוגדר
`prefers-reduced-motion` — הממשק קריא במלואו גם בלעדיהן. הקונספט הראשון נשאר
סטטי בכוונה, כחלק מהאופי שלו.

**אין סרטונים מצולמים בדמו.** בעמודי ההכנה שמור מקום מסומן לסרטון — הצילום
צריך להיעשות במלר״ד עצמו.
